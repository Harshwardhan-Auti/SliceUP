# SliceUP

> A fast-paced 2D slicing game built with Unity.

SliceUP is a 2D game prototype focused on simple, responsive slicing gameplay. The project was created as a hands-on Unity development project to experiment with 2D gameplay, player interaction, and game mechanics.

---

## 🎮 Gameplay

The core concept of SliceUP is simple:

**Slice → React → Score → Improve**

The player interacts with objects appearing in the game environment and uses slicing mechanics to interact with them.

The project focuses on keeping the gameplay:

* Simple
* Responsive
* Fast-paced
* Easy to understand
* Satisfying to play

## 🚀 Getting Started

### Requirements

* Unity
* Git
* Visual Studio / JetBrains Rider or another compatible C# IDE

### Installation

Clone the repository:

```bash
git clone https://github.com/Harshwardhan-Auti/SliceUP.git
```

Open **Unity Hub** and select:

```text
Add → Add project from disk
```

Select the cloned `SliceUP` folder.

Open the project using the compatible Unity version.

Open the game scene and press **Play**.
